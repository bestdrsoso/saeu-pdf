광고 없는 가벼운 PDF 뷰어/편집기. 쓰는 기능만.


[ 실행하는 법 ]
------------------------------------------------------------
방법 1) "실행하기.bat" 더블클릭  (Python 필요)
        처음 한 번은 라이브러리 설치로 시간이 걸립니다.
        Python 이 없으면 python.org 에서 먼저 설치하세요.

방법 2) "exe만들기.bat" 더블클릭 → dist\새우PDF.exe 생성
        이 exe 는 Python 없이 혼자 실행됩니다.


[ 기본 PDF 프로그램으로 쓰기 (다운로드 PDF 자동 열기) ]
------------------------------------------------------------
1) "exe만들기.bat" 으로 exe 를 먼저 만듭니다.
2) "기본앱등록.bat" 더블클릭 → 연결 프로그램에 등록됩니다.
3) 아무 PDF 우클릭 → 연결 프로그램 → 다른 앱 선택
   → "새우PDF" 고르고 [항상] 체크   (한 번만 하면 끝)
※ 되돌리려면 "기본앱해제.bat"


[ 화면 구성 ]
------------------------------------------------------------
위쪽 탭 : [홈] [변환]
  홈  : 파일(메뉴) / 보기 / 주석 / 삽입 / 스타일 / 찾기
  변환: PDF→이미지, 이미지→PDF, PDF→HWP

왼쪽  : 페이지 썸네일 (드래그해서 순서 변경)
아래쪽: 페이지 이동(◀ ▶) · 쪽 기능 전부 · 확대 슬라이더
        회전(↺ ↻) / 쪽삭제 / 쪽추출 / 뒤에합치기 / 여러개병합


[ 파일 열기 ]
------------------------------------------------------------
· 창 안으로 PDF 를 끌어다 놓으면 바로 열립니다 (여러 개도 가능)
· [파일] → 열기 에서 여러 개 선택 가능
· 2개 이상이면 "하나로 합쳐서 열까요?" 를 물어봅니다
  - 예    : 파일명 순서대로 합쳐서 한 문서로 열기
  - 아니오 : 첫 번째 파일만 열기
· 아래쪽 [여러개병합] : 여러 PDF 를 골라 하나로 합쳐 저장


[ 보기 ]
------------------------------------------------------------
· 드래그            : 도면이 끌려서 움직입니다 (기본 동작)
· 휠                : 위아래 스크롤 (페이지가 세로로 이어짐)
· Ctrl + 휠         : 확대 / 축소 — 마우스 커서가 있는 자리를 기준으로 커집니다
· 폭맞춤            : 가로를 화면에 꽉 채움 (창 크기 바뀌면 자동 추종)
· 화면맞춤          : 페이지 한 장이 통째로 보이게
· 아래쪽 확대 슬라이더로도 조절


[ 찾기 ]
------------------------------------------------------------
· 검색어 입력 후 Enter (또는 [찾기/다음])
· 같은 검색어로 다시 누르면 → 다음 결과로 이동
· 찾은 곳은 연노랑, 지금 보고 있는 곳은 주황 테두리로 구분됩니다
· [이전] 으로 뒤로, [표시지움] 으로 노란 표시 전부 제거
· 검색어를 지우고 Enter 쳐도 표시가 사라집니다


[ 편집 · 주석 ]  (홈 탭에서 도구 선택 후 화면에 드래그)
------------------------------------------------------------
· 손(이동)      : 기본 상태입니다(버튼 없음). 드래그하면 도면이 움직입니다.
                  다른 도구를 쓰다가 그 도구를 다시 누르면 여기로 돌아옵니다. (단축키 V)
· 형광펜        : 글자 높이에 맞춰 얇게 그어집니다
· 펜 / 사각형 / 원 / 선
· 텍스트상자    : 그냥 클릭만 해도 그 자리에 상자가 하나 생깁니다.
                  (크게 만들고 싶으면 드래그) 확정 후에도 도구가 유지되어
                  계속 클릭하면 하나씩 추가됩니다.
                  [확정] 또는 Ctrl+Enter / [취소] 또는 Esc
                  글자 크기는 "글자크기" 칸 값 그대로 들어갑니다
· 이미지        : 그림 파일을 고른 뒤 넣을 자리를 드래그
                  (서명·도장도 이걸로)
· 색 / 굵기 / 글자크기 는 도구 오른쪽에서 지정
  - [색] 을 누르면 자주 쓰는 색 10가지가 바로 나옵니다.
    더 세밀하게 고르려면 맨 아래 "다른 색…"
· 선택한 도구를 다시 누르면 해제되어 손/선택으로 돌아갑니다


[ 자동 업데이트 ]
------------------------------------------------------------
· 새우PDF 를 켜면 2초 뒤에 조용히 새 버전을 확인합니다.
· 새 버전이 있으면 "업데이트가 있습니다" 창이 뜹니다.
  [예] 를 누르면 알아서 받아서 교체하고 다시 시작합니다.
· 직접 확인하려면 : [파일] - 업데이트 확인
· exe 로 쓰는 경우는 자동 교체가 안 되고 알림만 뜹니다.
  (소스 폴더에서 exe만들기.bat 을 다시 실행하세요)
· 저장 안 한 내용이 있으면 재시작하지 않고 알려만 줍니다.


[ 오른쪽 클릭 메뉴 ]
------------------------------------------------------------
화면에서 마우스 오른쪽 버튼을 누르면 바로 쓸 수 있습니다.
 · 여기에 텍스트상자  (누른 그 자리에 생깁니다)
 · 여기에 이미지 넣기
 · 실행취소
 · 도구 바꾸기 (손/형광펜/펜/사각형/원/선/텍스트상자)
 · 이 쪽 ▸ 회전 / 삭제 / 쪽 추출 / 여러 PDF 병합
 · 폭맞춤 · 화면맞춤 · 저장 · 인쇄 미리보기
 · 단축키 설정


[ 단축키 ]
------------------------------------------------------------
 Ctrl+Z        실행취소 (하나씩 되돌리기, 최근 20단계)
 Ctrl+S        저장 (바로 덮어쓰기)
 Ctrl+Shift+S  다른 이름으로 저장
 Ctrl+O        열기
 Ctrl+P        인쇄 미리보기
 Ctrl+F        검색창으로        F3 / Shift+F3  다음 / 이전 찾기
 Ctrl+Shift+F  검색 표시 지우기
 Ctrl+0 폭맞춤   Ctrl+9 화면맞춤   Ctrl+= / Ctrl+- 확대 / 축소
 PgUp / PgDn   이전 / 다음 페이지

 도구 (글 쓰는 중에는 안 먹습니다)
 V 손/텍스트선택   H 형광펜   P 펜
 R 사각형   C 원   L 선   T 텍스트상자   I 이미지

 ※ 단축키 바꾸기 : 홈 탭의 [⌨ 단축키] 버튼
    (또는 [파일] → 단축키 설정, 오른쪽 클릭 → 단축키 설정)
    바꿀 칸을 클릭하고 원하는 키를 누른 뒤 [저장하고 적용] 누르면
    ※ 단축키를 없애려면 그 줄 오른쪽 [지우기] 버튼을 누르세요.
      (백스페이스·Delete 도 키로 인식되므로 지울 때는 [지우기] 사용)
    프로그램을 다시 켜지 않아도 바로 적용됩니다.
    [기본값으로] 를 누르면 처음 상태로 되돌아갑니다.
    (파일로 직접 고치고 싶으면 "shortcuts.json" 을 메모장으로 열어도 됩니다)


[ 알아둘 점 ]
------------------------------------------------------------
1. HWP 변환
   - 한컴오피스(한글)가 설치된 PC 에서만 됩니다.
   - 처음에 pip install pywin32 가 필요할 수 있습니다.

2. 형광펜
   - 글자 위를 그으면 글자 높이에 맞춰 얇게 칠해집니다.
   - 글자가 없는 빈 곳은 드래그한 영역 그대로 칠해집니다.

3. 실행취소
   - Ctrl+Z 로 주석·회전·삭제·합치기를 하나씩 되돌립니다.
   - 파일을 새로 열면 되돌리기 기록은 초기화됩니다.

4. 주석과 회전
   - 주석은 페이지를 회전하기 "전" 에 넣는 걸 권장합니다.

5. 저장
   - 제목에 * 표시가 있으면 저장 안 된 변경이 있다는 뜻입니다.
   - 여러 파일을 합쳐서 연 경우는 임시파일이라 Ctrl+Shift+S 로 저장하세요.
